# Lychee 3D Slicer - Supports On A Resin Plate You Named

## First Look at Lychee 3D Slicer

Lychee 3D Slicer is for a resin part you are allowed to print and a printer you already run. Lychee Slicer holds the supports. Lychee 3D is the same preview on that plate.

You open the model, you place it, you check the supports, you keep the project. You do not send a plate you have not looked at.

Lab staff and home users can use Lychee 3D Slicer in different ways, but the file should still be the one you named. Extra tests leave the working folder the same day.

The supports you keep should still match the part on the plate. If Lychee 3D looks wrong, stop and fix placement before you slice. Lychee Slicer is easier when the project sits next to the model you named.

## Quick Start with Lychee 3D Slicer

1. **Open Lychee 3D Slicer** - On the PC next to the resin printer you run.
2. **Load the part** - Use a model you are allowed to print.
3. **Place it** - Let Lychee Slicer sit the piece where the supports make sense.
4. **Preview** - Read Lychee 3D before you slice.
5. **Save the project** - Keep it beside the model in the folder you named.
6. **Send only then** - The printer should be the one you operate.
7. **Clean up** - Remove a test project you will not reprint.
